# CPSC 1710 Labs

Student-facing assignments and starter materials for CPSC 1710, Fall 2026.

## Labs

- [Lab 1: Meet a deep-learning notebook](lab-01/)
- [Lab 2: From one pixel to your classifier](lab-02/)

Open [`index.html`](index.html) for the visual course hub. Each assignment is available as a webpage and a printable PDF.

## Opening the files

The HTML files have no build step. You can open them directly in a browser, or serve the repository locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/`.
